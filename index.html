Gemini integration (draft)

SentinelQA uses Gemini 3 for goal-to-test planning, self-healing selectors, and failure triage. The agent turns user stories and UI intent into executable browser flows, adapts when selectors drift, and summarizes failures with reproducible steps and artifacts. Gemini 3’s reasoning capability powers the planner loop and the chaos-test evaluator so teams can ship faster with fewer regressions.
